# 🎵 Spotify Clone Website

## 📌 About the Project
This project is a Spotify Clone Website inspired by the design and user interface of Spotify. It is developed to practice front-end web development using HTML, CSS, and JavaScript.

## ✨ Features
- Clean and user-friendly interface
- Spotify-inspired design
- Music playlists and song lists
- Responsive layout (if implemented)
- Interactive music player (if implemented)

## 🛠️ Technologies Used
- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **JavaScript** – Interactive functionality

## 🚀 How to Run the Project
1. Clone this repository:
   ```bash
   git clone https://github.com/sanika-keskar/Spotify-Clone.git
   ```
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension if your project requires it.
